# Hacktoberfest Progress Tracker

## What it does

This small website checks GitHub pull requests opened by a username during a selected month. Merged and open pull requests count toward a personal goal, while closed pull requests that were not merged are shown but do not count.

## Tech used

- HTML, CSS, and plain JavaScript
- GitHub REST API
- GitHub Pages
- GitHub Student Developer Pack

## How to run it

Open `index.html` in a browser. No install or build step is needed.

## How to deploy on GitHub Pages

Create a public GitHub repository, push these files to the `main` branch, then open the repository's **Settings > Pages** page. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.

## Good to know

- GitHub Search API rate limits can affect requests.
- This is a personal progress estimate, not an official Hacktoberfest validator.
- Official Hacktoberfest rules can include extra requirements about eligible repositories and contributions.
- The GitHub Student Developer Pack may include useful developer tools and services; availability can change.
